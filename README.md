# Tribal Wars 🎮

Polytopia benzeri tur tabanlı strateji oyunu. Android mobil platformu için geliştirilmektedir.

## Özellikler
- ✅ Tur tabanlı strateji oyunu
- ✅ Offline Single Player (Bot AI)
- ✅ Bluetooth Multiplayer
- ✅ Çoklu dil desteği (Türkçe, İngilizce)
- ✅ Farklı aşiret türleri
- ✅ Çeşitli askeri birimler
- ✅ Dinamik harita sistemi

## Teknoloji Stack
- **Game Engine:** Unity
- **Dil:** C#
- **Platform:** Android
- **Multiplayer:** Bluetooth
